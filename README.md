University Management System
This Java-based University Management System allows users to manage students, teachers, and classes in a university setting. Users can perform various operations such as creating students, teachers, and classes, as well as viewing information about them. The system provides a console-based interface for user interaction.

Main Functionality
Print All Teachers: Displays a list of all teachers in the university along with their salaries.
Print All Classes: Displays a list of all classes in the university. Users can also view details of a selected class, including students enrolled and the teacher assigned.
Create a New Student: Allows users to create a new student by entering their name and age. Users can assign the student to one or more classes.
Create a New Class: Enables users to create a new class by providing the class name, classroom, and selecting a teacher. Users can also assign students to the class.
Create a New Teacher: Users can create a new teacher by entering their name, base salary, and selecting whether they're a full-time or part-time teacher.
List All Classes for a Student: Displays all classes that a selected student is enrolled in.
Exit: Exits the program.
