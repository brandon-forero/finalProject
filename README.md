# University Management System
This Java-based University Management System allows users to manage students, teachers, and classes in a university setting. Users can perform various operations such as creating students, teachers, and classes, as well as viewing information about them. The system provides a console-based interface for user interaction.

## Main Functionality
1. Print All Teachers: Displays a list of all teachers in the university along with their salaries.
2. Print All Classes: Displays a list of all classes in the university. Users can also view details of a selected class, including students enrolled and the teacher assigned.
3. **Create a New Student:** Allows users to create a new student by entering their name and age. Users can assign the student to one or more classes.
4. **Create a New Class:** Enables users to create a new class by providing the class name, classroom, and selecting a teacher. Users can also assign students to the class.
5. **Create a New Teacher:** Users can create a new teacher by entering their name, base salary, and selecting whether they're a full-time or part-time teacher.
6. **List All Classes for a Student:** Displays all classes that a selected student is enrolled in.
7. **Exit**: Exits the program.
## Instructions to Run
1. **Prerequisites**: Ensure you have Java Development Kit (JDK) installed on your machine.
2. **Clone the Repository:** Download the source code files from the repository.
3. **Compile and execute:** Open your command line or terminal and navigate to the directory containing the Java files. Use the following command to compile (or just in your ide like VS code or intellij:

javac Main.java Class.java Student.java Teacher.java FullTimeTeacher.java PartTimeTeacher.java University.java

Run the Program: After compiling, run the program using the following command:

java Main

4. **Follow the Prompts:** Use the menu options displayed in the console to interact with the system.
